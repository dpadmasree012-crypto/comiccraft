# ComicCraft: AI Comic Story Creator using Gemini Models

ComicCraft is a web-based application that uses AI to generate personalized comic book stories and illustrations based on user-provided prompts.

## ✨ Features
- **AI Story Generation:** Uses Gemini to create a structured 5-panel comic outline and full narration.
- **AI Illustrations:** Free image generation via Pollinations.ai.
- **Simple UI:** Clean form for entering story prompt, character, setting, tone, and art style.

## 🛠️ Tech Stack
- **Backend:** FastAPI, Python
- **Frontend:** HTML, CSS, Jinja2
- **AI Text:** Google Gemini (`gemini-3.8-flash`)
- **AI Images:** Pollinations.ai (free, no API key)
- **PDF Generation:** fpdf2
